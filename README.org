This project is hugo theme for [[https://github.com/takeokunn/blog][takeokunn/blog]].

https://www.takeokunn.org/

** Run locally
#+begin_src console
  $ cd exampleSite
  $ hugo server --themesDir ../..
#+end_src
** Configuration

Theme settings go in the =[params]= table of the site's =hugo.toml=. Each key is optional. The table below gives the default where the theme sets one. The block below is a trimmed copy of =exampleSite/hugo.toml=.

#+begin_src toml
[params]
DateForm = "2006.01.02"
brand = "{name}.blog"
mainSections = ["posts"]
featuredArticles = ["/posts/table-of-content", "/posts/markdown-syntax", "/posts/rich-content"]
popularPosts = []  # an empty list hides the Popular panel
editURL = "https://github.com/OWNER/REPO/edit/main/content"
selfHostFonts = false

[params.author]
name = "Author"
role = "Software engineer · Tokyo"
bio = "A short bio shown on Home, the footer, and About."
topics = ["Hugo", "Emacs", "Nix"]

[params.home]
greeting = ""

[params.social]
github = "https://github.com/..."
zenn = "https://zenn.dev/..."
twitter = "https://x.com/..."

[params.socialHandles]
github = "@..."

[params.tagColors]
Hugo = "pink"
Nix = "orange"

[[params.pdfLinks]]
title = "sample-slides"
url = "/pdf/sample-slides.pdf"
date = "2024-03-08"
event = "Event name 2024"
#+end_src

| Key | Meaning |
|---|---|
| =DateForm= | Go time layout for dates in lists and articles. Default: =2006.01.02=. |
| =brand= | Text of the header and footer brand. The placeholder ={name}= is replaced by =author.name=. Default: ={name}.blog=. |
| =mainSections= | Sections whose pages count as articles on Home and in the post count. |
| =featuredArticles= | Site-relative URL paths of up to three articles shown under "Featured" on Home. |
| =popularPosts= | Paths shown under "Popular" in the Posts sidebar. An empty list hides the panel. |
| =editURL= | Base URL of the "edit this page" link. The article's path relative to =content/=, such as =posts/x/index.md=, is appended. |
| =selfHostFonts= | When =true=, the theme links the site's own =static/fonts/fonts.css= instead of Google Fonts. The theme does not ship that file; the site must provide it with the @font-face rules for the three families. |
| =author.name= | Name in the header brand and the footer. |
| =author.role= | Role line on Home and About. |
| =author.bio= | Bio in the footer and the author card. |
| =author.topics= | Topics listed in the default Home greeting. |
| =home.greeting= | Home heading. An empty string uses the default greeting. |
| =social.<service>= | Link for each icon. Services: =github=, =zenn=, =twitter=, =keyoxide=, =rss=. Without =rss=, the feed at =/index.xml= is linked. |
| =socialHandles.<service>= | Handle text for a service, using the same service names as =social=. |
| =tagColors.<tag>= | Color of a tag: =pink=, =cyan=, =purple=, =green=, =orange=, or =yellow=. Tags without an entry get a color from a hash of their name. |
| =pdfLinks= | Slides listed under "Talks". Each entry has =title=, =url=, =date=, and =event=. |

Home lists the 20 most used tags with a link to the Tags page, which lists every tag.

Some site settings outside =[params]= change how the theme renders. =hasCJKLanguage = true= counts Japanese characters in word counts. =[markup.highlight] noClasses = false= makes code colors come from the theme's CSS, so they follow the selected theme. =[related]= chooses related articles; the example weights the tags index at 100 and the date index at 10.

To check that the theme builds with no params, run this in =exampleSite=. =hugo.unset.toml= is =hugo.toml= without =[params]=, =[menus]=, and =[Languages.ja-jp.params]=.

#+begin_src console
  $ cd exampleSite
  $ hugo --config hugo.unset.toml --themesDir ../..
#+end_src

** i18n

UI text comes from =i18n/ja.toml=, =i18n/ja-jp.toml=, and =i18n/en.toml=. =ja-jp.toml= is for the =ja-jp= language, the exampleSite's default. =ja.toml= is for =ja=. Each key is a table with an =other= value. Templates call the key with =i18n "key"=.

Keys with a placeholder take data. Pass a number for =.Count= (=i18n "minRead" .ReadingTime=), or a dict for named values (=i18n "themeToggle" (dict "Name" "Dracula")=).

When you add or rename a key, change all three files so they hold the same keys. To check for missing keys, run =hugo --printI18nWarnings --themesDir ../..= in =exampleSite=.

** Theme switching

The theme has two palettes: Dracula (dark, the default) and Alucard (light). The header button and the mobile menu switch between them and save the choice in =localStorage= under =theme=. Without a saved choice, the theme follows the OS =prefers-color-scheme= setting. An inline script in =layouts/partials/meta/standard.html= sets =data-theme= on =<html>= before the first paint.

Colors are CSS custom properties defined in =assets/sass/_tokens.scss=. Use the role names (for example =--color-text= or =--color-surface=) in other Sass files instead of hex colors.

** About page

Set =layout: about= in the front matter of the About page. The exampleSite uses =content/pages/about.md=.

#+begin_src yaml
layout: about
timeline:
  - { date: "2024.03", title: "Talk title", note: "sample-slides" }
#+end_src

=timeline= is optional. Each entry has =date=, =title=, and =note=.

** Article front matter

The following front matter keys are optional.

#+begin_src yaml
description: "Lead text for lists and the article header"
points: ["First takeaway", "Second takeaway", "Third takeaway"]
lastmod: 2024-01-10
#+end_src

- =description= is the lead text. Without it, Hugo's =.Summary=, as plain text cut to 80 characters, is used.
- =points= fills the "What you'll learn" panel. The panel is hidden when =points= is absent.
- =lastmod= adds an "Updated" pill. The pill appears only when the date differs from the publish date.

** OGP images

Post images are generated in =static/ogp/=. For =content/posts/example.md= the filename is =example.png=; for =content/posts/example/index.md= it is also =example.png=, based on the bundle directory name. Names must be unique because identical names overwrite the same PNG. Other pages use =assets/ogp/site.png=.

To override an image, set =images= to a list of URLs in front matter; the first URL is used. If =images= is absent or empty, the legacy =image= string is used. Otherwise the generated post image or site image is used. Relative URLs are resolved against the site base URL, and absolute URLs are used as given.

To generate article images, install [[https://github.com/Ladicle/tcardgen][tcardgen]] 0.10.0 and make it available on =PATH=. Run the following from the Hugo site root, replacing =themes/hugo-take-theme= with the theme location and =content/posts= with the posts directory if needed.

#+begin_src sh
  python3 -m pip install Pillow
  themes/hugo-take-theme/scripts/ogp/fetch_fonts.sh
  python3 themes/hugo-take-theme/scripts/ogp/build_assets.py \
    --name Author --topics Hugo Emacs Nix Design \
    --avatar themes/hugo-take-theme/assets/icons/avatar.png --out assets/ogp
  themes/hugo-take-theme/scripts/ogp/generate.sh content/posts
#+end_src

The font script downloads M PLUS Rounded 1c Regular, Medium, Bold, and ExtraBold into =fonts/ogp/=. Keep their filenames unchanged. To use another font directory, set =FONTS= when running =generate.sh=; the default is =fonts/ogp/=. The site root must contain =assets/ogp/tcard-template.png=: tcardgen resolves the template path from the current directory. The =build_assets.py= command above creates it along with =assets/ogp/site.png=. Replace =Author=, the topics, and the avatar path to customize them. The site’s =assets/ogp/= overrides the theme assets.

Each post needs front matter like this YAML example. Both =author= and =categories= must be nonempty for tcardgen.

#+begin_src yaml
  title: Example post
  author: Author
  categories: [blog]
  tags: [Hugo]
  date: 2023-02-01T00:00:00Z
  images: ["https://example.com/custom.png"] # Optional override
#+end_src

Run the generation command before each Hugo build in the deployment pipeline so the generated =static/ogp/= PNG files are included in the published site. The generated files do not need to be committed.

Titles longer than three lines can overlap the tags. Around 45 full-width characters is a guide, though English words may wrap earlier. Check titles with =python3 themes/hugo-take-theme/scripts/ogp/preview.py --check content/posts=. The check warns about long titles without failing the build. Shorten the title or specify a custom image in =images= when needed.
